# 简历项目描述（结果占位版）

## 项目名称

Kaggle Featured Competition｜长时序自主决策 Agent 与对局评测系统

## 可直接使用的能力描述

- 设计模块化长时序决策 Agent，将 720 回合农业经济模拟拆分为状态解析、资源规划、多人任务调度、动态市场决策、对手建模与合法动作保护。
- 建立固定随机种子、双座位、三类官方对手的可复现评测体系，并以胜率、平均净胜差、方差和失败标签驱动策略消融。
- 构建赛外 LLM Replay Analyst，将结构化回放转化为证据化失败归因和候选实验，所有 LLM 建议均通过对照实验验证后再进入策略。
